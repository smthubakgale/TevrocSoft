Getting started

Follow the tester group invitation to find the app installation link. These screenshots show what to expect along the way.

Open the group invitation

Join the VoltFlow Testers group using the button above. In the group, find the welcome message and select its installation link to open VoltFlow on Google Play.

2 Install and test

Use the link in the group welcome message to open this Google Play listing, install VoltFlow, and leave it installed for the full 14-day testing period.
